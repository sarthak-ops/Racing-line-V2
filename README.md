This project implements an iterative geometric racing-line optimization algorithm in Python. The track is represented using a cubic spline and sampled into discrete nodes, with each racing-line point represented by a lateral displacement from the centerline. At each iteration, neighboring racing-line points are used to calculate a local angle bisector, which determines how each point should move laterally to produce a smoother and shorter racing line. Displacements are constrained to remain within the track boundaries, and the final racing line is visualized alongside the centerline and track boundaries. This approach was adapted from OneLoneCoder's Programming Racing Lines implementation and serves as the geometric foundation for the more advanced vehicle-dynamics/lap-time optimization planned for later versions.
